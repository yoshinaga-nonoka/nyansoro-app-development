## 1. Mac でやること：アップロード

1. `main`（release-1.0 を取り込んだあと）を pull して Xcode で開く
2. ターゲット Nyansoro →「Signing & Capabilities」→ Team に自分の有料アカウント（Apple Developer Program）を選ぶ
3. 上の端末の選択を「Any iOS Device (arm64)」にする
4. メニュー「Product」→「Archive」
5. 終わると Organizer が開く →「Distribute App」→「App Store Connect」→「Upload」
6. 15〜30分ほどで App Store Connect の「TestFlight」にビルドが出る

### ⚠️ TestFlight で試すとき
TestFlight のビルドは Release なので **本物の広告** が出る。
**自分で広告をタップしない**こと（AdMob の規約違反で、アカウントが止められることがある）。
心配なら AdMob の管理画面「設定 → テストデバイス」に自分の iPhone を登録しておくと、その端末ではテスト広告になる。

### プロモーション用テキスト（170字まで・審査なしでいつでも変えられる）
> 6家族・18匹の猫の牌を集めて、3組そろえたら「にゃん！」。リーチや役で点数アップ、勝てば★でランクアップ。毎日の1局で連続記録をのばそう。

### 説明文
```
かわいい猫の牌を集めて、3組そろえたら上がり！
ルールはシンプル、でも奥が深い。猫の牌合わせゲームです。

■ あそびかた
・手札は8枚。1枚引いて1枚捨てる、をくり返します
・「同じ猫3枚」か「同じ家族のパパ・ママ・子猫」で1組
・9枚で3組そろったら上がり。人が捨てた牌でも上がれます
・招き猫はどの猫にもなれる、うれしいお助け牌

■ 点数と役
・自分で引いて上がるとボーナス、招き猫なしでもボーナス
・リーチ、すぐにゃん、パパ／ママ／子猫そろい、家族と兄弟、最後の1枚、ひと家族だらけ…
・役を重ねて高い点をねらおう

■ 強くなれる仕組み
・はじめてでも安心。最初に説明と練習3つで、遊びながらルールが分かります
・上達レッスンで、点数の数え方や「待ち」の考え方を学べます
・1局ごとに「ベストな捨て方」の割合をふりかえり
・目標をクリアすると称号がもらえます

■ CPU対戦でランクアップ
・子猫 → 家猫 → 野良猫 → ボス猫 → 猫神様
・上のランクほどCPUが強くなり、場の色も変わります

■ 毎日の1局
・毎日ちがう配牌で、みんな同じ条件の1局
・連続記録をのばそう

■ そのほか
・漢字にふりがな付き（設定で消せます）
・ログイン不要、通信がなくても遊べます
・広告で無料。最初の3試合は広告なし
```

## 4. App のプライバシー（データの扱い）
アプリ自身は何も集めない（セーブは端末の中だけ、サーバーなし）。
集めるのは **広告の SDK（Google Mobile Ads）** なので、その分を申告する。

**必ず Google の公式ページで最新の一覧を確認してから入れる：**
https://developers.google.com/admob/ios/privacy/data-disclosure

目安（公式ページと照らし合わせること）：
| データの種類 | 目的 | 追跡に使う |
|---|---|---|
| 位置情報 → おおよその位置（IP アドレスから） | 他社の広告、分析 | |
| ID → デバイス ID（広告 ID） | 他社の広告、分析 | はい（追跡を許可された場合） |
| 使用状況 → 製品の操作、広告データ | 他社の広告、分析 | |
| 診断 → クラッシュ、パフォーマンス、その他の診断 | 分析 | |

「データの収集：はい」→ 上の種類を選ぶ → 目的と「追跡」を公式ページどおりに選ぶ。
